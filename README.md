# Santiago Gonzalez — Portfolio

A responsive, animated portfolio built with plain HTML, CSS, and JavaScript. It runs directly in a browser; no server or package installation is needed.

## Open it locally

Open `index.html` in a browser.

## Edit your profile

Update profile copy, work history, skills, and links in `static/content.js` inside the `window.PORTFOLIO` object. The layout is in `index.html`, styling and responsive behavior are in `static/style.css`, and interactions are in `static/app.js`.

## Host on GitHub Pages

This folder is ready to publish as the root of a GitHub repository. Create a repository, upload these files, then enable GitHub Pages in the repository settings using **Deploy from a branch** and the `main` branch with the `/ (root)` folder. The site will be available at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/` after Pages finishes its first deployment.

The site saves the selected color theme in the browser and respects reduced-motion accessibility settings.
